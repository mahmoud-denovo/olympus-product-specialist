# DeNovo Olympus Product Specialist

AI-First Web Platform & Technical Specialist for Olympus/Evident Microscopy Systems.

## Features
- **Deterministic Optical Compatibility Rules:** Checks microscope stands against observation modes and objective lens series.
- **Hierarchical Token & Quota Tracking:** Real-time telemetry monitoring cost and token usage.
- **FastAPI SSE Gateway:** High-performance server with Server-Sent Events streaming.
- **Local-First Architecture:** 3 Local Subagents ($0 Cost) and Resilient Circuit Breaker.

## Setup
```bash
pip install -e .
python -m pytest tests/ -v
```
